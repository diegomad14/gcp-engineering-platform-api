# Service Onboarding Checklist

- [ ] Service owner identified.
- [ ] Runtime service account created.
- [ ] WIF deployer service account configured.
- [ ] Artifact Registry repository exists.
- [ ] Cloud Run service names chosen.
- [ ] Health endpoint defined.
- [ ] Rollback revision documented.
- [ ] Secret Manager inventory documented without values.
- [ ] PR check workflow adapted.
- [ ] Candidate/promote/rollback workflows reviewed.
- [ ] Behavior-level release gates defined.
- [ ] Data and PII policy reviewed.
- [ ] Runbooks linked from service catalog.
